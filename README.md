# 值班交接单

一张表，解决一个问题：**交接班的时候，信息丢了。**

## 为什么做这个

我值了一年多的班，经历过几次 P1 故障。有一次网络断了，我知道连接数归零，但不知道是哪条链路断的——这些是事后问网络组才知道的。

值班的人看得到症状，看不到病因。**交接班是唯一能传递这个信息的场合。** 所以做了这张表。

## 表长什么样

一行一件事，五列：

**日期 / 班次 / 时间 / 待交接事项 / 备注**

本班没有要交接的，就在「待交接事项」里填**「无」**。

## 想不起来该写什么，就扫一遍这张表

| # | 什么 | 一句话检查 |
|---|---|---|
| 1 | 没闭环的事件 | 上一班走的时候，还有哪几件没画上句号？ |
| 2 | 正在进行的变更 | 现在有变更吗？几点结束？回滚怎么回？ |
| 3 | 临时规避措施 | 系统现在靠什么撑着？什么时候到期？ |
| 4 | 外部依赖状态 | 运营商、云厂商现在正常吗？ |
| 5 | 快到阈值的资源 | 有什么东西在慢慢变坏，只是还没叫？ |
| 6 | 差点出事的事 | 这一班有没有什么差点就出事了？ |
| 7 | 待办的人和时间 | 每件事有没有具体的人名和时间？ |
| 8 | "恢复了"是哪一层 | 告警消失？业务可用？根因消除？ |

## 怎么用

打开 `templates/值班交接单模板.xlsx`，「示例」页看一眼就懂，照着填。

填的时候记住一条：**现象写事实，判断写假设，别混在一起。** "连接数归零"是事实，"链路断了"是判断。

## 说明

示例数据全是虚构的。
